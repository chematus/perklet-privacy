# Perklet

Perklet is an independent Android app for following Twitch Drops: choose your games, monitor reward progress, and claim rewards when they're ready.

- [Visit the Perklet website](https://perklet.app/)
- [Get Perklet on Google Play](https://play.google.com/store/apps/details?id=app.perklet)

Perklet is available on Google Play for compatible Android devices. Availability may vary by country and device.

The product website is a single-page landing page. The former mobile-guide URL forwards to the homepage; it no longer serves a separate article. Legal pages remain separate.

The homepage title, description and concise product copy describe Twitch Drops tracking and automatic claiming on Android. A short `meta keywords` list is included as requested, but Google ignores this tag for indexing and ranking; it is not a substitute for useful page content.

This repository hosts the public website, [privacy policy](https://perklet.app/privacy/), and [account and data deletion instructions](https://perklet.app/data-deletion/). It does not contain the Android app's source code.

# Perklet

Perklet is an independent Android app for following Twitch Drops: choose your games, monitor reward progress, and claim rewards when they're ready.

- [Visit the Perklet website](https://perklet.app/)
- [Get Perklet on Google Play](https://play.google.com/store/apps/details?id=app.perklet)

Perklet is currently in testing. Use the Google account enrolled in the test to access the Play Store listing; it may be hidden from other accounts.

This repository hosts the public website, [privacy policy](https://perklet.app/privacy/), and [account and data deletion instructions](https://perklet.app/data-deletion/). It does not contain the Android app's source code.
